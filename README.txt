SSL — Sunday Super League Season 2 · UI Refresh v5

NEW FEATURES
1. Live league table: generated team badges, last-five form indicators (W/D/L), wins, draws, losses, goals for/against, goal difference, points, and a highlighted leader.
2. Match Centre: filters for all/upcoming/recent matches and by team; responsive match cards; expandable scorecards; admin score entry; award selection inside completed match scorecards.
3. Player of the Match: award cards show player, team, match score, goals and assists. Admin selects the winner after a result is entered. Award selections sync to Firebase at league/playerOfMatch.

PLAYER PHOTOS
- Put player photos in images/players/ with lowercase hyphenated names, e.g. images/players/jack.jpg.
- If a photo is absent, initials are shown instead.
- Keep the full poster as images/image2.jpg. The large hero image card remains removed and the page background remains more visible.
